# 생성형 AI 문제풀이 (Luna)

1. `LunaQuiz.exe`를 더블클릭합니다.
2. **기준점**에서 게임 창 전체를 드래그합니다. 보라색 테두리는 다음 실행 때 창을 맞추는 위치 표시입니다.
3. **퀴즈 영역**에는 그림, 질문, 보기가 모두 들어가게 드래그합니다. 청록색 테두리가 표시됩니다.
4. 영역을 하나 이상 지정한 뒤 **프리셋 1~3**의 슬롯을 고르고 **프리셋 저장**을 누릅니다. 지정한 영역만 저장됩니다. 같은 슬롯에 다시 저장하면 해당 슬롯의 위치가 갱신됩니다.
5. 다음 실행 때 슬롯을 고르고 **불러오기**를 누르면 저장된 테두리가 표시됩니다. 기준점도 저장했다면 게임 창을 보라색 테두리에 맞춥니다.
6. Luna 창을 퀴즈 영역 밖으로 옮기고 **시작**을 누릅니다.

프리셋은 Windows 사용자별로 `%LOCALAPPDATA%\LunaQuiz\Presets`에 저장합니다. 모니터 배치나 게임 창 크기가 바뀌었다면 영역을 다시 지정해 저장하세요.

현재 퀴즈 영역의 **학습용 캡처**를 먼저 준비하세요. 프로그램은 오른쪽 위 초록색 타이머 아이콘으로 퀴즈 창을 감지하고 `1/3`, `2/3`, `3/3` 표시로 현재 문제를 구분합니다. 같은 번호가 연속해서 확인되면 퀴즈 영역을 약 1.7초 동안 다섯 번 캡처해 GPT-6.1 Terra에 보냅니다. 타이머 숫자와 문제 본문은 문제 전환 판정에서 제외됩니다. 기준점은 위치 안내에만 쓰이며, 화면에 표시된 HUD 테두리는 앱의 캡처에 포함되지 않습니다.

로그인된 Codex CLI 또는 Codex 데스크톱 앱과 GPT-6.1 Terra를 사용할 수 있는 계정이 필요합니다.

**시작**을 누르면 본창이 최소화되고 작은 창이 열립니다. 작은 창에서 프리셋 불러오기, 테스트 모드, 시작/중지, 현재 상태와 풀이 결과를 사용할 수 있습니다. **본창**을 누르면 감시를 중지하고 원래 창으로 돌아갑니다.

**시작**을 누른 뒤 퀴즈 창을 앞에 두세요. Luna가 정답 좌표를 반환하면 같은 문제가 표시 중인지, 입력할 위치가 마지막 캡처와 같은지 확인하고 보기를 클릭합니다. O/X 문제는 모든 보기의 좌표를 받아 각 문장을 해당 칸으로 순서대로 옮깁니다. 입력 위치가 불분명하면 답만 표시하며, 입력 도중 문제나 대상이 바뀌면 남은 드래그를 중지합니다. 자동 입력을 멈추려면 **중지**를 누르세요.

마우스 입력 없이 확인하려면 **테스트 모드**를 체크하고 **시작**을 누르세요. 같은 검증을 거친 뒤 클릭할 위치는 노란 원으로, 드래그는 노란 시작점에서 초록색 도착점까지 화살표로 약 4초간 표시합니다. 모드를 바꾸려면 **중지**를 누른 뒤 체크 상태를 변경하세요.

## Codex 세션과 규칙

첫 풀이에서 Codex 세션을 만들고, 퀴즈가 바뀌거나 프로그램을 다시 실행해도 같은 세션을 이어서 사용합니다. 세션 ID는 `%LOCALAPPDATA%\LunaQuiz\codex-session.txt`에 저장됩니다. 답변과 화면 동작을 처리한 직후 임시 캡처 5장을 삭제하며, Codex가 로컬에 저장한 세션 기록과 그 안의 이미지 사본은 유지됩니다.

이전 풀이를 보거나 규칙을 바꾸려면 **중지**를 누르고 **세션 명령 복사**를 선택한 뒤 PowerShell에 붙여 넣어 실행하세요. 예를 들어 세션에 `LUNA QUIZ RULES: 회전 문제는 그림의 방향과 위치 변화를 따로 비교해.`라고 보내면 이후 풀이가 그 규칙을 참고합니다. 규칙을 수정하려면 같은 제목으로 새 규칙을 보내세요. 이번 캡처 5장만 근거로 사용하며 응답 형식과 자동 입력 검증은 그대로 적용됩니다. 규칙을 보낸 뒤 터미널의 Codex 세션을 종료하고 LunaQuiz에서 다시 **시작**을 누르세요.

## 캡처 미리보기

퀴즈 영역을 지정한 뒤 **캡처 미리보기**를 누르면 왼쪽에 실제 캡처, 오른쪽에 Windows OCR이 읽은 원문이 표시됩니다. 아래 상태 줄에서 캡처 크기와 OCR 결과를 확인할 수 있습니다. 두 창이 퀴즈 영역을 가리지 않도록 옮기세요.

미리보기는 PC에서만 갱신되며 자동 풀이는 일시 중지됩니다. **시작**을 누르면 미리보기가 닫히고 자동 풀이가 다시 시작됩니다.

## 학습용 캡처

**퀴즈 영역**을 지정하거나 프리셋을 불러온 뒤 **학습용 캡처**를 누르세요. 두 Luna 창을 캡처 영역 밖으로 옮긴 다음, 실제 화면에 맞춰 **평소 화면**, **1번 문제**, **2번 문제**, **3번 문제** 버튼을 누르세요. 한 번 누를 때마다 PNG 한 장이 추가됩니다. 같은 분류도 여러 번 저장할 수 있습니다.

**저장 폴더 열기**를 누르면 현재 캡처 영역의 폴더가 열립니다. 저장 위치는 `%LOCALAPPDATA%\LunaQuiz\Training` 아래이며, 영역의 위치와 크기별로 폴더를 나눕니다. 이 창을 열면 자동 풀이가 중지되고 캡처 이미지는 PC에 저장됩니다.

**시작**을 누를 때 해당 영역의 폴더에서 네 분류를 읽어 감지 템플릿을 만듭니다. 현재 감지 영역은 762×586 학습 화면에서 확인한 오른쪽 위 배치를 기준으로 합니다. 퀴즈 창 배치나 확대 배율이 달라지면 오른쪽 위 표시가 캡처에서 같은 위치에 들어오는지 확인하세요.

## 앱 업데이트

실행 시와 실행 중 5분마다 GitHub의 최신 정식 릴리스를 확인합니다. 새 버전이 있으면 본창의 **업데이트** 버튼이 초록색으로 활성화됩니다. 버튼을 누르면 풀이를 중지하고, 창 배경 위에 흐림 효과와 회전 링, 다운로드 진행률을 표시합니다. 검증이 완료되면 실행 파일을 교체하고 자동으로 다시 실행합니다. 프리셋과 학습 이미지는 Windows 사용자 폴더에 보관됩니다.

최초 업데이트 기능을 사용하려면 [GitHub Releases](https://github.com/trick86155-ship-it/gpt-quiz/releases/latest)에서 업데이트 기능이 포함된 실행 파일을 한 번 받아 실행하세요.

새 버전은 `powershell -ExecutionPolicy Bypass -File Publish-Luna.ps1 -Version 1.0.1 -Notes "변경 내용"`으로 게시합니다. 먼저 GitHub CLI 로그인이 필요하며, 실행 중인 LunaQuiz는 닫아야 합니다. 스크립트는 검증과 빌드 후 실행 파일과 체크섬을 초안 릴리스에 업로드하고, 두 파일을 확인한 뒤 정식 배포합니다. 다음 게시 때는 버전 번호를 높이세요.

## 실행 파일 빌드

Windows PowerShell에서 `Build-Luna.ps1`을 실행하면 같은 폴더에 `LunaQuiz.exe`가 생성됩니다. 메이플스토리 서체 저작권은 ㈜넥슨코리아에 있습니다. 이용 조건은 `LICENSE-Maplestory.txt`를 참조하세요.
